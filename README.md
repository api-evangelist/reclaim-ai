AI-powered scheduling platform with a REST API for managing tasks, habits, meeting buffers, and automatically optimizing calendar time for deep work and meetings. Reclaim integrates with Google Calendar and Outlook to protect focus time, improve meeting quality, and provide workforce scheduling analytics.

**Areas:** Artificial Intelligence · Scheduling · Calendar · Productivity · Task · Habits · Time Management · Meetings · Focus Time

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Reclaim.ai: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
